# Arayüz dili (i18n)

EVREN Desktop çok dilli arayüz için hafif, bağımlılıksız bir i18n katmanı kullanır.
Şu an **Türkçe (tr)** ve **İngilizce (en)** desteklenir; Türkçe varsayılandır.

## Kullanım

Dil, **Ayarlar → Genel → Dil** bölümünden değiştirilir ve `settings.json` içindeki
`locale` alanına yazılır. Değişiklik anında uygulanır (yeniden başlatma gerekmez).

Bileşen içinde:

```tsx
import { useI18n } from '../i18n'

function Ornek(): React.JSX.Element {
  const { t, locale, setLocale } = useI18n()
  return <button title={t('composer.send')}>{t('common.save')}</button>
}
```

Yer tutucular:

```tsx
t('composer.queueDropped', { count: 3 }) // "3 sıradaki istem iptal edildi."
```

React dışında (main süreç, testler) `translate(key, params)` kullanılabilir.

## Dosyalar

| Dosya | İçerik |
|---|---|
| `src/renderer/src/i18n/tr.ts` | Türkçe sözlük — **ana kaynak** |
| `src/renderer/src/i18n/en.ts` | İngilizce sözlük |
| `src/renderer/src/i18n/index.ts` | Dil deposu, `useI18n`, `translate`, `formatMessage` |
| `src/shared/types.ts` | `Locale = 'tr' \| 'en'` |

## Yeni anahtar ekleme

1. `tr.ts` içine anahtarı yaz (nokta ile ad alanı: `settings.language`).
2. `en.ts` içine aynı anahtarı yaz. **Eksik çeviri derleme hatası verir**
   (`Record<TranslationKey, string>`).
3. Yer tutucular iki dilde birebir aynı olmalı; `npm run test:unit` bunu denetler.

## Yeni dil ekleme

1. `src/shared/types.ts` → `Locale` tipine ekle.
2. `src/renderer/src/i18n/<dil>.ts` dosyasını oluştur (`Record<TranslationKey, string>`).
3. `src/renderer/src/i18n/index.ts` → `LOCALES`, `LOCALE_LABELS`, `DICTIONARIES` güncelle.
4. `src/main/settings.ts` → `normalizeSettings` içindeki dil doğrulamasına ekle.

## Çözümleme ve geri düşme

`translate` sırası: geçerli dil → Türkçe → anahtarın kendisi. Eksik anahtar arayüzü
bozmaz, anahtar metni görünür ve testte yakalanır.

## Kapsam (kademeli geçiş)

Taşınan yüzeyler:

- Pencere denetimleri (`WindowControls`)
- Karşılama ekranı (`Onboarding`)
- Güncelleme paneli (`UpdatePanel`)
- Ayarlar: başlık, sekmeler, Genel sekmesi (bağlantı, görünüm, dil, API anahtarı,
  güncellemeler, günlükler)
- Besteci: yer tutucular, gönder/durdur/araya gir/sıraya al, istem geçmişi, kuyruk
  rozetleri ve bildirimleri

Henüz taşınmayan yüzeyler (Türkçe kalır): sohbet balonları ve araç kartları, çalışma
alanı/oturum listesi, MCP tarayıcısı, uzantı/hafıza/GitHub/görev panelleri, ajan paneli,
terminal paneli, komut paleti, hata sınırı.

Bir yüzeyi taşırken: metni `tr.ts` + `en.ts`'e ekle, bileşende `useI18n()` çağır,
sabit metni `t(...)` ile değiştir. Kalan Türkçe metinler hata değildir; kademeli geçiş
bilinçli bir tercihtir.

## Testler

```bash
node scripts/run-unit.cjs scripts/i18n-test.ts            # 24 senaryo
node scripts/run-unit.cjs scripts/settings-rules-test.ts  # dil ayarı doğrulaması
```

`i18n-test` şunları denetler: sözlük anahtar eşitliği, boş çeviri yokluğu, yer tutucu
tutarlılığı, dil doğrulama, çeviri çözümleme ve biçimlendirme.

## Sınırlar

- Ana süreç hata mesajları (`ApiError` metinleri) hâlâ Türkçedir; bunlar teknik
  ayrıntı olarak kabul edilir ve çevrilmemiştir.
- Tarih/sayı biçimlendirme `Intl` ile dile bağlanmadı; `formatNumber` sabit
  biçimlendirme kullanır.
- Sağdan sola (RTL) diller için düzen desteği yok.
