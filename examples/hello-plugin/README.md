# Hello Plugin (örnek)

EVREN Desktop eklenti formatına minimal örnek.

- `evren.extension.json` — manifest
- `index.js` — `register(api)` ile `word_count` aracı

Kurulum: repo'yu GitHub'a koyun → EVREN Desktop → Ayarlar → Uzantılar →
Eklentiler → GitHub'dan ekle.

Ayrıntılar: `docs/PLUGIN-FORMAT.md`.
