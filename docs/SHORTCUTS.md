# Klavye Kısayolları ve Komut Paleti

## Global komut paleti

**Ctrl+K** (macOS: Cmd+K) ile açılır. Etiket/anahtar kelimeye göre arar:

- Yeni sohbet
- Ayarlar / Hafıza / Uzantılar
- Çalışma alanı seç
- İnceleme / Dosyalar / Git / Görevler panelleri
- Plan / Build modu
- Mesaj kutusuna odaklan
- Model değiştirme (oturumdaki modeller)

`↑` / `↓` gezinir, `Enter` çalıştırır, `Esc` kapatır. Eşleşmeler önce etiket,
sonra açıklama/anahtar kelimeye göre sıralanır.

## Kısayollar

| Kısayol | İşlem |
|---|---|
| `Ctrl+K` | Global komut paleti |
| `Ctrl+N` | Yeni sohbet |
| `Ctrl+,` | Ayarlar |
| `Ctrl+Shift+R` | İnceleme panelini aç/kapat |
| `Ctrl+Shift+F` | Dosyalar panelini aç/kapat |
| `Ctrl+Shift+G` | Git panelini aç/kapat |
| `Ctrl+Shift+T` | Görevler panelini aç/kapat |
| `Shift+Tab` (composer) | Plan / Build modu |
| `Enter` | Mesajı gönder |
| `Shift+Enter` | Yeni satır |
| `Esc` | Palet/menü kapat |

## Pencere / sistem

- Özel başlık çubuğu: sürükle, küçült, büyüt/geri yükle, kapat.
- Sistem tepsisi: **Göster / Gizle / Çıkış**.
- Yanıt veya arka plan alt-ajan görevi bitince, pencere odakta değilse
  Windows bildirimi gösterilir.
- Beklenmeyen arayüz hatasında **hata sınırı** devreye girer; hata kopyalanabilir
  veya arayüz yeniden yüklenebilir.
